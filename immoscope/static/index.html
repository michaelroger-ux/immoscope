Importer des annonces

Collez l'adresse d'une annonce ou d'une page de résultats. Certains sites bloquent les requêtes automatiques : utilisez alors le marque-page.

Glissez ce bouton dans la barre de favoris de votre navigateur. Sur une page d'annonce (ou de résultats) que vous consultez, cliquez dessus : la page est envoyée à Immoscope, qui en extrait les annonces.

Envoyer à Immoscope

Fonctionne tant qu'Immoscope tourne sur cet ordinateur. Seule la page affichée est envoyée, une fois, à votre demande.

Sur la page de l'annonce : clic droit → « Afficher le code source », tout sélectionner, copier, puis coller ici.
